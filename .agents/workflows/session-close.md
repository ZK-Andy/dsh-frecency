# 会话收尾检查单（session-close）

> 每个开发批次完成或会话结束时执行（可多轮触发，由 feature-flow 步骤 7 调用）；全部完成才算收尾。

1. **提交对账**：`git log` 本会话全部提交——每条提交能对应到决策/变更。
2. **决策落档（结论只落 durable 家）**：本轮拍板结论是否已进 ADR / `docs/cookbook.md` / README / AGENTS？没有则补。
3. **待办对账**：跨会话遗留项写入 HANDOFF-todos（若有）或明确告知用户。
4. **README 核对同步**：若本批次改了功能/行为，核对 README 与 shipped 现实，必要时同步。
5. **未推送提醒**：本地领先 origin 的提交数如实告知用户；是否推送由用户定。
6. **工作树确认**：`git status` 干净；untracked 仅限预期清单（HANDOFF.md、`.plan/` 等）。
7. **收尾汇报**：向用户说明本批次结果、README 结论、遗留待办。

> 交换/延续机制：项目有跨会话需求时，按 `HANDOFF.md` 维护交换主文档（本地，可选不入提交）；未启用前仅在收尾汇报中说明状态。
